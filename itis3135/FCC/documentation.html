Introduction

JavaScript is a programming language used to build interactive websites.

It runs in the browser and allows developers to create dynamic behavior.

  • Client-side scripting
  • Event handling
console.log("Hello World");

Variables

Variables store data values.

JavaScript supports var, let, and const.

let name = "Matthew"; const age = 25;
  • let is block scoped

Functions

Functions allow reusable blocks of code.

They can accept parameters and return values.

function greet() { return "Hello"; }
  • Reusable

Loops

Loops execute code repeatedly.

Common loops include for and while.

for(let i = 0; i < 5; i++) {}
  • For loop

Arrays

Arrays store multiple values in one variable.

They are indexed starting at zero.

let numbers = [1,2,3];
  • Indexed structure
