Client Project Structure

This page outlines the foundational structure for the flower service website. The site is designed to help visitors explore flowers by occasion, learn about arrangements, and contact the florist for custom orders.

Website Purpose

The client project is a flower-focused service website that provides users with helpful guidance for selecting floral arrangements for birthdays, anniversaries, sympathy gifts, weddings, and other meaningful events.

Planned Page Structure

  1. Home (index.html) — Introduces the flower business, highlights featured arrangements, and welcomes visitors to the site.
  2. About (about.html) — Shares the florist’s story, mission, and commitment to quality service.
  3. Flower Guide (guide.html) — Explains common flower types and which occasions they best fit.
  4. Gallery (gallery.html) — Displays arrangement examples and featured floral designs.
  5. Contact (contact.html) — Gives visitors a way to reach out for questions, custom requests, or consultation details.

Navigation Expectations

Every page in the client project should use the same navigation bar in the same location so users can move through the website easily. The page names should be clear, relevant to the flower service, and connected naturally to the file names.

Design Direction

  • Soft floral color palette
  • Readable layout using semantic HTML5 elements
  • Simple navigation with a welcoming homepage
  • Visual emphasis on featured flowers and occasions
  • Clear sections for business information and contact details

Next Development Steps

After this structure page is complete, the next stage is building the actual five required pages with consistent styling, working navigation, and real content that supports the flower service concept.
